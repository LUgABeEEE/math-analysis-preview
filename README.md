# 数学分析 · 上册预习讲义

**在线版**：https://lugabeeee.github.io/math-analysis-preview/

写给数学系大一新生的《数学分析》上册预习讲义，按**华东师范大学数学科学学院编《数学分析》第六版（上册）**的章节顺序编排。

## 特点

- **单文件、完全离线**：整本讲义是一个 `index.html`，公式用 MathJax 矢量渲染、内联在文件里，断网也能正常阅读。
- **预习 + 正式内容并存**：每章开头「课前 3 问」→ 本章地图 → 定义与白话解释 → 交互实验 → 证明与例题 → 章末自测。左下角可切「只看预习线」。
- **9 个可拖动交互实验**：上确界、ε-N、ε-δ、一致收敛、割线→切线、Taylor 逼近、二分法、Riemann 和、p 积分。纯 Canvas 手写，无外部依赖。
- **一页速览**：全学期十二件事的骨架表，5 分钟建立全局。
- **附录**：A 公式速查、B 二十题综合自测（答案折叠）、C 十六周学习路线。

## 重新构建

```bash
# 依赖：Python 3；MathJax 已放在 assets/tex-svg.js（如需更新，从 cdn.jsdelivr.net 下载 tex-svg.js）
python3 build.py        # 生成 index.html
python3 make_sample.py ch2   # 可选：抽出单章样张
```

源文件在 `src/`：`shell.html` 是模板（样式 + 交互引擎），其余按章节拆分，`zz-appendix.html` 是附录。编号在构建期写入，不依赖 CSS counter。
